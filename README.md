SyFlow — Шлях до чистого коду
«Старі крила згоріли, щоб нові могли розпуститися. Русло тече, а камінь стоїть — отже русло завжди змиє каміння і покаже свою велич».

SyFlow — це інтерактивна навчальна платформа нового покоління, створена для тих, хто прагне опанувати мистецтво програмування через гармонію теорії та практики. Це преображення проєкту SyPy, що перетворилося на сучасну екосистему з використанням найпотужніших технологій.

🌊 Про проєкт
SyFlow побудований на принципах чистоти коду та динамічного навчання. Проєкт поєднує в собі:

Інтерактивні курси: Навчання Python, HTML, CSS та JavaScript.

Гейміфікацію: Система рангів (від «Кодового хробака» до майстра) та досягнень.

Економіку SyNit: Внутрішня валюта, що винагороджує за чистий та ефективний код.

Живий інтерфейс: Плавність рухів завдяки анімаціям та миттєвій навігації.

🛠 Технологічний стек
Для створення ідеального «потоку» ми використовуємо:

Backend (Серце системи)
Django — надійний фундамент.

Django Rest Framework (DRF) — міст між даними та користувачем.

Simple JWT — безпека та захист твоїх скарбів.

Frontend (Обличчя системи)
React — нервова система інтерфейсу.

React Router — карта для вільної навігації.

Framer Motion — гармонія та плавність анімацій.

Bootstrap & FontAwesome — естетика та впізнаваність символів.

📁 Структура проєкту
Проєкт організований за принципом чистого розділення обов'язків:

/backend/ — логіка сервера, бази даних та API.

/ReactBlock/ — інтерактивна частина платформи на React.
